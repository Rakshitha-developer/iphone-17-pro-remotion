# iPhone 17 Pro (Cosmic Orange) — Remotion Video

30-second (900 frames @ 30fps, 1920×1080) Apple-style product motion graphics project.

## Setup & Render

1. Place your two reference images into `public/`:
   - `public/iphone-17-pro-orange.png`
   - `public/apple-logo.png`
2. Install dependencies:
   ```bash
   npm install
   ```
3. Preview in Remotion Studio:
   ```bash
   npm run dev
   ```
4. Render the final MP4:
   ```bash
   npx remotion render MainVideo out/iphone-17-pro-cosmic-orange.mp4
   ```
